# 🏥 JASHS See-QR

**Emergency Health QR Code System for Jose Abad Santos High School**

A lightweight, offline-first student health record system. Generate QR codes containing student medical information that can be scanned and viewed instantly — even without internet.

---

## ✨ Features

- 📱 **100% Offline Support** — Student QR codes work forever without internet
- 🏷️ **Student Medical QR** — Scan with any phone camera → instant access to emergency health info
- ➕ **Offline Data Entry** — Add new records on any device, no server required
- 💾 **Export & Import** — Share records between devices easily
- 🌐 **Web Access** — Available online via GitHub Pages when you need remote access
- 🎨 Clean, simple interface — no account needed
